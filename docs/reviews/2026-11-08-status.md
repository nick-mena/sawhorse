# Status, 2026-11-08

Where the macOS fork stands after the first day of work: what was done, what has been proven, and what is left. The findings behind the stability work (B and S numbers) are in [the baseline review](2026-11-08-baseline-review.md).

## Where the code is

- Branch `fix/stability-pass`, with no upstream set, so nothing here has been pushed.
- Commit `20ae35f` holds the stability pass and its docs.
- **Everything else below is uncommitted** in the working tree: pointers and trackpad, trust fixes, type, Stock Stamp, fonts and shortcuts.

## Done

### Stability (committed)

- Fixed B1 to B6, B8, B9, S1, upstream #27 and the symlink half of S8. Saving now works on models that had a solid removed, and the read-back check stayed strict.
- Open, New and Quit ask before discarding work. A sequence fuzzer ran 20,000 sessions with no failure.
- Added `AGENTS.md`, the review above and a lean set of macOS tests.

### Navigation and pointer

- The pointer shows the active tool: a crosshair with the tool's icon beside it.
- On a trackpad, two-finger swipe orbits, Shift+swipe pans, and Cmd+swipe or pinch zooms. A mouse wheel still zooms.
- Trackpad orbit speed is a setting (Edit > Settings…), starting at 50%.

### Trust and Mac fit

- The top bar shows the file name and Edited or Saved state, and the window title follows it.
- Unsaved work now offers Save, Don't Save and Cancel. A successful save says the file read back as this model.
- Menus and messages say Cmd and use Mac key glyphs on a Mac. Tapping Cmd works as Ctrl does in the tools.
- All five dialogs hold keyboard focus and hand it back on closing (`useDialogFocus`).

### Look

- Type roles are defined as tokens in `rem`, and cut sizes are no longer the smallest text in the panel.
- The accent is a warm marking colour. Selection stays blue so it stands out on wood.
- **Stock Stamp:** each part gets a numbered stamp that matches across the Cut list, the model, the nesting diagrams and the printed labels. Tags renumber if the list changes.
- The trial of three themes was built and then removed at the owner's request.

### Fonts

- Open Sans replaces Barlow Condensed and IBM Plex Sans, and Noto Sans Mono replaces IBM Plex Mono. Both are bundled under the SIL Open Font License.
- Labels are sentence case with no condensed capitals. Monospace is kept for columns of numbers, typed values and code.
- Autodesk's own typeface, Artifakt, is proprietary and limited to Autodesk's business, so it is neither used nor included. Open Sans was chosen by eye as an open font in the same spirit. It has not been compared side by side with Artifakt or a current copy of Maya, and no source confirmed the font in current Maya builds.
- The marketing site (`site/`), the original mock (`docs/mock/`) and exported drawings keep their own fonts.

### Keyboard shortcuts

- Edit > Keyboard Shortcuts… lists every key. Tool, file, edit and Zoom Extents keys can be changed, cleared or reset, one at a time or all together.
- It refuses keys that would break typing or belong to the system, explains why, and asks before taking a key from another command.
- The menus, tool rail, tooltips and status messages all follow the keys chosen. Each key is saved on this device.
- Fixed keys and a running plugin's keys are listed for reference but cannot be edited here.

- The Save / Don't Save / Cancel dialog, the window title and Cmd+Q.

- Ad-hoc signing on a real downloaded `.dmg`.
